This is a digital menu app built using react native (Expo) for the chef to be able to edit, update, delete or add new meals.


## features of the app 
1. u are able to view all dishes that were added.
2. you are able to add new dishes, their name,type ,description as well as their price.
3. You are able to edit existing dishes.
4. you are able to delete dishes but first confirms with u ,if u are sure.


## Technologies used
1 React Native
Expo SDK
JavaScript
Typescript
